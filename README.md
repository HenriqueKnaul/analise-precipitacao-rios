# Análise da Relação entre Precipitação e Nível dos Rios no Alto Vale

> Sistema destinado a analisar a relação entre a quantidade de chuva registrada e a posterior elevação do nível dos rios do Alto Vale do Itajaí.

## 📌 Sobre o Projeto
A aplicação utilizará dados históricos para apresentar gráficos, comparações e identificar quanto tempo após períodos de chuva intensa ocorre uma elevação significativa dos rios, auxiliando na compreensão e prevenção de eventos críticos na região.
